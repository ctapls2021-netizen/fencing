# Social ads UI kit
Paid-social compositions based on the ads in the brand guide (`assets/reference/ad-*.jpg`). Each ad is a fixed-size React component at native resolution (1080 wide), previewed scaled.
- AdStoryPremium (1080×1920), AdFeedWoodLook (1080×1350), AdStoryCollage (1080×1920), AdSquarePergola (1080×1080, new composition using the pergola landing-page hero language).
Rules: one offer, one CTA; gold for the number/CTA, blue for the frame; logo always present; seal badge top-right when space allows.
