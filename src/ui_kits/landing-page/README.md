# Landing-page UI kit
Recreation of the two paid-traffic landing pages in `uploads/Mulnolland - Marketing.jpg`: **Gates and Fences** and **Pergolas**. Toggle pages with the switcher bottom-left.
- `shared.jsx` — Hero, PhotoRow, Mosaic, Testimonials, Faq helpers
- `gates.jsx` — Gates & Fences page · `pergolas.jsx` — Pergolas page · `fencing.jsx` — 60% Off Fencing Google Ads LP (standalone: `Fencing 60 Off.html`; copy from `uploads/Mulholland - 60% Off Fencing LP.pdf`)
Interactive: hero/closing forms submit to a confirmation state, FAQ accordions, header CTA jumps to the form, hover states on tiles/CTAs.
Photos are cropped from the comp (low-res ~960px); swap in originals for production.
